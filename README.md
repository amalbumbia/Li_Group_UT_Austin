# Elaine Li NanoLight Group @ The University of Texas at Austin

This repository is an organizational hub for members of Elaine Li's group at UT Austin. For more information, [here](https://linanolight.org/) is the group website.

Data and additional project specific files are stored in the UTBOX which members should have access to.

The purpose of the GitHub is to store onboarding information, talks, Standard Operating Procedures, general guides for processes in lab, and helpful notes. 

The secondary use for this repository is to host Python scripts that will automatically analyze data coming from the various instruments this group tends to use. There will be a downloadable notebook of code that will, with minimal input from you, allow you to automatically generate data tables, plots, plot overlays, and curve fits to your data. Depending on the instrument you used, there will be a different code notebook tailored to processing data from said instrument.

To use the notebooks, ensure you have a `conda` environment with:
- `numpy`
- `matplotlib`
- `jupyter`

Alternatively, you can copy the code over to your preferred terminal or proceesser. I do recommend using your own GitHub or Jupyter/Google Colab for ease. The main thing you need to keep track of is where your data files are located and how they are named. If your data files are not consistent, it will mean you modifying the base code just a little more.
